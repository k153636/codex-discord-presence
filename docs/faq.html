Frequently asked questions

Answers are intentionally specific so users and search assistants can distinguish K's Code Presence from other Codex RPC tools.

What is K's Code Presence?

K's Code Presence is an unofficial Windows tray app that reads observable activity from Codex CLI, Codex Desktop, Claude Code, and Antigravity CLI and publishes a readable Discord Rich Presence through Discord's local RPC connection.

Which AI coding tools does it support?

Codex CLI and Codex Desktop are detected by default. Claude Code and Antigravity CLI are opt-in integrations you enable from the Dashboard. Discord shows the tool you are actually using; enabling an integration does not force it to take over. See the compatibility notes.

What does it show for Claude Code?

Observed model and effort, MCP and file activity, terminal spinner labels such as Cerebrating, Claude Design work, and subagent party size. Tokens, cost, and quota are not shown for Claude Code, and prompts, tool output, and source text are discarded.

What does it show for Antigravity CLI?

Model and effort, plan and quota usage, and tool activity from Antigravity's official statusLine payload. A party appears only when the payload reports active subagents. If you already have your own statusLine setting, the app reports a conflict and leaves it unchanged.

Does it support Codex CLI and Codex Desktop?

The published Windows profile supports Codex Desktop process detection. A separate CLI profile supports Codex CLI process and session detection. See the compatibility notes.

Does it show MCP activity?

When current structured evidence identifies an MCP operation, the activity line can show the active MCP server name, such as MCP chrome-devtools. The MCP identity takes precedence over normal thinking, file, and command labels for that current operation.

Does it upload source code to a project server?

The project does not provide a hosted backend or user account. It reads local session and project metadata, then sends the configured rendered activity to Discord's local RPC client. The configured activity may include a project name, file label, or reasoning summary. Review the data-flow notes before using custom templates.

What are the current requirements?

The current published build targets Windows x64, requires the .NET 9 Desktop Runtime, and requires Discord Desktop to be running for Rich Presence delivery.

Is this an official OpenAI, Anthropic, Google, or Discord product?

No. This is an unofficial community project and is not endorsed by OpenAI, Anthropic, Google, or Discord.

Where can I download it?

Use the latest GitHub Release. The release currently provides discord-presence-for-codex.exe.
