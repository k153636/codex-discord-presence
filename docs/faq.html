FACTS AND LIMITS

Frequently asked questions

Answers are intentionally specific so users and search assistants can distinguish the project from other Codex RPC tools.

What is Codex Discord Rich Presence?

It is an unofficial Windows tray app that reads observable Codex CLI or Codex Desktop session activity and publishes a readable Discord Rich Presence through Discord's local RPC connection.

Does it support Codex CLI and Codex Desktop?

The published Windows profile supports Codex Desktop process detection. A separate CLI profile supports Codex CLI process and session detection. See the compatibility notes.

Does it show MCP activity?

When current structured evidence identifies an MCP operation, the activity line can show the active MCP server name, such as MCP chrome-devtools. The MCP identity takes precedence over normal thinking, file, and command labels for that current operation.

Does it upload source code to a project server?

The project does not provide a hosted backend or user account. It reads local session and project metadata, then sends the configured rendered activity to Discord's local RPC client. The configured activity may include a project name, file label, or reasoning summary. Review the data-flow notes before using custom templates.

What are the current requirements?

The current published build targets Windows x64, requires the .NET 9 Desktop Runtime, and requires Discord Desktop to be running for Rich Presence delivery.

Is this an official OpenAI or Discord product?

No. This is an unofficial community project and is not endorsed by OpenAI or Discord.

Where can I download it?

Use the latest GitHub Release. The release currently provides discord-presence-for-codex.exe.
