UNOFFICIAL WINDOWS DEVELOPER TOOL

Show what Codex is doing in Discord.

Codex Discord Rich Presence is a local Windows tray app for Codex CLI and Codex Desktop. It turns observable session activity into a readable Discord status without requiring a project account or hosted service.

Download for Windows View source

Windows x64 · .NET 9 Desktop Runtime · Discord Desktop required

OBSERVABLE ACTIVITY

What it shows

Current work

Thinking, researching, running commands, editing files, creating or deleting files, waiting, and completed work when the local session provides evidence.

MCP identity

When an MCP operation is current, the activity line can show the active server, such as MCP chrome-devtools, without mixing it with stale file or reasoning text.

Project context

Model and reasoning effort, project name, Git changed-file count, recent edited file, session duration, and configured Discord buttons.

LOCAL DATA FLOW

Designed around local evidence

The app reads local Codex session JSONL and configuration data, observes the active project and Git context, resolves a current activity state, and sends the rendered Rich Presence to Discord's local RPC client.

The project does not offer a cloud backend or require a user account. The configured activity can still expose project names, file labels, or reasoning summaries to Discord, so review your templates before sharing.

The app may contact GitHub for release update checks and may use configured external image URLs for Discord assets. See the data-flow notes for the current boundaries.

BEFORE YOU INSTALL

Requirements and limits

  • Windows x64 and the .NET 9 Desktop Runtime are required for the current published build.
  • Discord Desktop must be running for local Rich Presence delivery.
  • The app is unofficial and is not endorsed by OpenAI or Discord.
  • If direct Codex evidence is unavailable, the app falls back to the configured recent-file and timestamp evidence.
